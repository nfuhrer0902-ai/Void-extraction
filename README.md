# Void Extraction
Original Android top-down sci-fi extraction shooter prototype.

## Controls
- Left thumb: movement joystick.
- Right side: aim/fire.
- Kill 15 hostiles, then enter the green extraction zone.

## Build entirely from a phone using GitHub
1. Create a new GitHub repository.
2. Upload the contents of this project ZIP, preserving folders including `.github/workflows`.
3. Commit to the `main` branch.
4. Open the repository's Actions tab and select **Build Android APK**.
5. Run the workflow if it did not run automatically.
6. When the build finishes, open it and download the `VoidExtraction-debug-apk` artifact.
7. Unzip the artifact on Android and install `app-debug.apk`. Android may ask you to allow installs from the browser/file manager you used.

This prototype uses only programmatically drawn original graphics, so there are no copyrighted Halo or Call of Duty assets bundled with it.
